# 🟡 Simplified Pac-Man (Godot)

A simplified recreation of the classic **Pac-Man**, built with **Godot** as part of my game development learning journey.

## 🎮 Gameplay

Navigate the maze, and avoid obstacles while exploring a simplified version of the classic arcade experience.

### Current Features

- 🟡 Smooth Pac-Man movement
- 🧱 Maze built using Godot's TileMap
- 🎮 Keyboard controls

---

## 🛠️ Built With

- **Godot Engine**
- **GDScript**

---

## 📚 Learning Goals

This project helps me practice:

- Collision detection
- Scene organization
- Signals
- Animation
- Game state management
---

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/Merve-1/Game-Development.git
```

2. Open the project using **Godot**.

3. Press **F5** to run the game.
