# 🚀 Chicken Game (Godot)

A 2D arcade space shooter inspired by the classic **Chicken Invaders**, built with **Godot** as part of my game development learning journey.

> **Disclaimer:** This is a fan-made practice project created for educational purposes only. It is **not** affiliated with or endorsed by the creators of Chicken Invaders.

## 🎮 Gameplay

Control your spaceship and survive waves of invading space chickens.

Current features:

- 🚀 Player movement
- 🔫 Shooting system
- 🐔 Enemy chickens
- ⭐ Space background
- 💯 Score system
- ❤️ Basic game loop

## 🛠️ Built With

- **Godot Engine**
- **GDScript**

## 📚 Learning Goals

This project is helping me practice:

- Scene organization
- Node-based architecture
- Signals
- Physics and collisions
- Animation
- UI creation
- Game state management
- Object spawning
- Writing clean GDScript

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/Merve-1/Game-Development.git
```

2. Open the project with Godot.

3. Press **F5** to run the game.
